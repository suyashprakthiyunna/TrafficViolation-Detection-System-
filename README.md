# Traffic Violation Detection System

## Overview
The Traffic Violation Detection System is an AI-powered web application that detects traffic rule violations using CCTV cameras and live camera feeds. It helps traffic police monitor roads, identify violations, and generate digital evidence.

## Features
- AI-based vehicle detection
- Number plate recognition
- Helmet detection
- Seat belt detection
- Speed violation detection
- Wrong lane detection
- Traffic signal violation detection
- Fine management system
- Officer login system
- Dashboard with live statistics
- Camera and video upload support

## How to Run
1. Download the project.
2. Open the project in VS Code or IntelliJ IDEA.
3. Install the required dependencies.
4. Run the Spring Boot application.
5. Open the application in your browser.
